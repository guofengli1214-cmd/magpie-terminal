1

本机固定第一，不参与 SSH 排序

本机 永远是第一张卡，带当前标记和 4 个 shell。SSH 列表按最近连接排，搜索不会把本机过滤掉。

2

shell 选择只影响新标签

bash / cmd / PowerShell 7 / PowerShell 5.1 四选一。已经开着的终端不重启，避免丢历史；选完直接反映到顶部 + 菜单。

3

点外部一定关得掉

遮罩覆盖终端和文件面板，点遮罩、按 Esc、点右上角都可以关闭。关闭后焦点回到终端，不留下半开的浮层。

1

文件跟着终端目录，不跟着主机面板

主机是覆盖层，文件是终端下方的固定面板。终端 cd 到哪，文件面板就跟到哪；分界条可拖 150–420px，拖到最下只剩 38px 标题条。

2

图标网格优先于树

列数跟着宽度走：1280 宽约 11 列，窗口变窄自动减少；面板高 224px，正好两行图标。文件名一行截断，元信息第二行。目录蓝、代码黄、JSON 绿、图片紫。

3

右键按类型给操作

右键按选中类型给操作：文件夹可打开、重命名、删除，文件多一个编辑；多选后底部出现批量条。删除是红色，且进入审批，AI 不能绕过。

4

上传不抢终端焦点

上传按钮打开文件选择器，进度在面板内的条目里走。终端保持输入焦点，不弹全屏对话框。
